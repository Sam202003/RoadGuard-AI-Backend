# @roadguard/api

MVP backend entry point. All modules (auth, vehicle, breakdown, …) will live here until split into microservices.

## Scripts

- `pnpm dev` — watch mode (from repo root)
- `pnpm build` — compile TypeScript
- `pnpm start` — run compiled `dist/main.js`

## Env

Copy `.env.example` to `.env` in this folder.
